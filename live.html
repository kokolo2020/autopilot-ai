Setup guide

How to set up the Tokyo server and the KuCoin key (about 15 minutes)
  1. Server: create a small VPS in Tokyo (Vultr "Cloud Compute, Regular, 1 GB" or Linode "Nanode", about $5/month), image Ubuntu 24.04. Open its web console or SSH in.
  2. Install: run sudo -i then bash <(curl -fsSL https://auto-pilotai.netlify.app/live/install.sh). It prints the server IP, the server address and your live key.
  3. KuCoin key: KuCoin website → API Management → Create API. Name it "autopilot". Permissions: General + Futures (trade) only. Never tick Withdrawal or Transfer. IP restriction: on, add the server IP. Set a passphrase you don't use elsewhere.
  4. Save the key on the server: run sudo kclive-setkeys and paste key, secret, passphrase (hidden).
  5. Money: in KuCoin, transfer the USDT you want to use (e.g. $300 for 10 coins at $25 plus room) from Funding/Trading into the Futures account.
  6. Here: paste the server address and live key above, pick coins, press Start in DRY RUN, check the activity log, then switch Settings to LIVE.
